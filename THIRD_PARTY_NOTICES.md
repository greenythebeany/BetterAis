## Made for this project

- **Language flags** - Hand-drawn SVG versions of the UK, Czech and Slovak national flags (icons.js). National flag designs are public domain.
- **File-type badges** - The coloured document icons with the file extension printed on them (icons.js) - drawn for this project.
- **Layout, styles and scripts** - All CSS and JavaScript in this extension - written for this project.
