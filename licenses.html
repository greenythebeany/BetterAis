Settings are stored only in the browser (chrome.storage / localStorage). Nothing is sent anywhere, except the font request to Google Fonts.

Third-party components

  • Tabler IconsMIT

    Every icon BetterAis draws in place of the site's own (dashboard, app grid, notices, breadcrumbs, table toolbar) and the graduation cap in the page loader. Embedded as inline SVG in icons.js and loader.js.

  • RobotoSIL Open Font License 1.1

    Typeface for the redesigned site and the popup. Not bundled - loaded from Google Fonts (fonts.googleapis.com).

  • CatppuccinMIT

    Colour palettes for the Mocha, Macchiato, Frappé and Latte presets (themes.css).

  • DraculaMIT

    Colour palette for the Dracula preset (themes.css).

  • NordMIT

    Colour palette for the Nord preset (themes.css).

  • GruvboxMIT

    Colour palettes for the Gruvbox Dark and Light presets (themes.css). Original by morhetz (Pavel Pertsev); license text from the maintained gruvbox-community fork.

  • Tokyo NightMIT

    Colour palette for the Tokyo Night preset (themes.css).

  • Rosé PineMIT

    Colour palettes for the Rosé Pine, Moon and Dawn presets (themes.css).

  • KanagawaMIT

    Colour palette for the Kanagawa preset (themes.css).

  • SolarizedMIT

    Colour palettes for the Solarized Dark and Light presets (themes.css).

Made for this project

  • Language flagsOriginal

    Hand-drawn SVG versions of the UK, Czech and Slovak national flags (icons.js). National flag designs are public domain.

  • File-type badgesOriginal

    The coloured document icons with the file extension printed on them (icons.js) - drawn for this project.

  • Layout, styles and scriptsOriginal

    All CSS and JavaScript in this extension - written for this project.
